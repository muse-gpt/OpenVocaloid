# OpenVocaloid — 可控歌声合成产品

与 [OpenSFX](../OpenSFX)（八族参数化音效合成）成对的**人声合成**产品仓。

- 目标：可控歌声合成（乐谱/音符时值、歌词、音素对齐、音高与表现控制）与说话语音合成（文本、语言、发音、韵律），不以变声或音频文件播放替代从符号输入合成。
- 当前状态：**待建设**。真实合成引擎、可分发模型与声库授权尚在核实选型；占位波形与已有素材播放不构成人声合成交付。
- 合同：`规划设计/media.rs/03-产品定位与连续动画创作合同.md` §3.1（人声）/ §3.2（音效）；验收为可懂度、音高/时长控制、跨音节连续性与可听缺陷，不用「WAV 非空」替代可听验收。
- 历史：本仓曾用作 Muse 案例工程（残光 / 残响花园 / 六兆年），Muse 媒体链路已随 G7 归位共享核心；案例内容现位于 [`examples/muse-cases`](../examples/muse-cases)。
